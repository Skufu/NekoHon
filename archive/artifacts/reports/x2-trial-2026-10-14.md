# smallbook_x2 live trial — fragment-pattern observations (2026-10-14)

The user tests with real-world sloppiness: fragments ("what is", "Location"),
greetings ("hey", "warrup"), bare topics ("DE Lifecycle"), comparisons with
the order flipped ("DDR5 vs ddr4" / "ddr4 vs ddr5"), trailing letters
("speed of ddr5s"). That surface is where the finetune is weakest. Raw
repro of all ten queries on both models through the app seam (answer mode):
`probe-trial-queries-2026-10-14.{json,log}`.

## Classification

- **Model warts** (x2 false-refuses where the 7B answers, all in-book):
  Location, DE Lifecycle, ddr4-vs-ddr5 — same disease as CRU/Codd: the
  decision margin sits a hair from refusal on any form not memorized
  exactly.
- **Engine items** (model-independent, backlog — fix after the session so
  trial attribution stays clean): "hey" -> `Read as: "they"` over-repair on
  greetings; "ddr5s" plural not repaired by either model; "what is"
  degenerate input answered with a passage.
- **Both-models-bad**: "what is", "speed of ddr5s". The 7B is not clean on
  this surface either (stray `Not in this book.` inside an answer).

## Effect on the next session design (proposed)

Slot A (x2c) widens to this pattern: ~30 of the 167 answer rows swapped in
place (counts and ratio held) to perturbed forms — lowercase fragments,
order flips, abbreviations/plurals. Slot B stays the seed control.
Acceptance probe for x2c = this probe's ten queries plus the batteries;
target: match the 7B on the three model warts, keep refusals 2/2 and loops
at zero.

## Pre-registered swap gate (written 2026-10-14, BEFORE x2c trains)

Committed before seeing any x2c / seed-control numbers so the pass/fail
rule cannot be negotiated after the fact. Temperature 0 throughout;
fragment/loop checks count draws (>= 10), not single runs; recordings
land in dated probe logs.

For a candidate to replace the trial default:

1. Refusals: France + iops exact (2/2); no in-book false refusal in the
   sealed fragment suite beyond the 7B's own misses on the same suite.
2. Fragment suite (new file, sealed, never trained): per-class pass rate
   >= the 7B's (classes: fragment, greeting, bare topic, order flip,
   trailing letter). The ten queries above are NOT the suite — they are
   visible targets.
3. No loops: 0 length-stops in the capped sweep (all 21 battery questions
   x 5 draws) and in the fragment suite (x 10 draws).
4. Battery: pin-pass rate not worse than x2's recorded 18-19/21, compared
   at equal draw counts, not single-run counts.
5. Quant check: the candidate's warts persist at high precision (q8_0
   export of the same run) — a wart that vanishes at q8_0 is a
   quantization verdict, not a training verdict.
6. Revert rehearsal: `ANSWER_MODEL=qwen2.5:7b` starts and passes the
   battery once during the trial. Done 2026-10-14: golden 10/10 (bar 8),
   typos PASS, probes PASS, France PASS; default engine restored after.
   Evidence: `evidence/step2-battery/step2-battery-revert-rehearsal-2026-10-14.{json,log}`
   plus the env-seam launcher copy `start-revert-rehearsal-2026-10-14.bat`.

Clean-bench note: the 4 assisted bench items (contamination audit
`probe-contamination-2026-10-14.log`) are reported separately; gate
claims about bench numbers use the clean subset.

Findings:

- **Seed control diverged** from x2 on identical data (battery -1..-2 pins;
fragment/bare/trailing regressions). Per the pre-registered read-out, n=1
run comparisons in this history are unreliable; x2c was judged only against
the absolute gate items above, and any unmatched "better/worse than x2"
claim is unsupported.
- Gate 2 (suite per-class >= 7B): **FAIL for both quants** — bare-topic
(10-11/50 vs 50/50), order-flip (19/40 best vs 40/40), trailing-letter
(20/30 best vs 30/30); q4 additionally fails fragment. Both quants beat 7B
on control refusals (20/20 vs 10/20).
- Gate 4 (battery, pre-registered text: not worse than x2's recorded 18-19
at equal draws): q8 19/19/19 **passes**; q4 18/18/18 sits on the boundary.
Correction note: the amendments' added "max(7B, x2)" reading (from the
audit flag) overstates the pre-registered text; it is superseded by this
note, and the 7B battery numbers (20-21/21) are reported separately.
- Gate 5 (quant): several q4 failures do **not** persist at q8 — fragment
0/40 -> 20/40, order 10/40 -> 19/40, trailing 10/30 -> 20/30, battery
18 -> 19. Per the pre-registered rule this is a quantization verdict:
those q4 failures are (at least partly) q4 artifacts, not training verdicts.
- Data-attributable win vs the seed control: Codd refusal fixed (x2 and
seed fail it; x2c passes in every run). CRUD/CRU pass in x2c and seed
alike (not isolable from session variance).
- Loops: 0 in every new run (x2c, q8, seed; suite + sweep). x2's recorded
File Formats length-stop did not reproduce on a same-data retrain — the
near-tie branch, not a stable defect (`loop-mechanism-analysis-2026-10-14.md`).
- Deterministic new failures logged for x2d: source-systems wrong chunk
(q4: ch05-004 vs pin ch02-005), extracted-in-ETL/-ET wrong chunk or
refusal (both quants), insert-only wrong chunk (every model incl. x2),
bare-topic uncited answers (Time Series, Micro-Batch, Streaming, Event
Streams), 'explain'/'why does' fragment citing, pipeliness.
- Visible-ten acceptance (the trial-doc target for x2c): Location, DE
Lifecycle and ddr4-vs-ddr5 — the three user warts — are all answered by
x2c now (q4: some uncited; q8: cited for Location and DE Lifecycle),
refusals hold (10/10) and loops stay zero. 'hey' still over-repairs
(engine item, both quants); 'warrup' still refuses cleanly. Evidence:
`evidence/probe-trial-queries/…model-smallbook_x2c{,q8}.{json,log}`.
On the narrow user-facing ten, x2c meets its target; the gate fails on
the wider sealed suite, which is why the decision split below matters.

**Verdict: x2c is not adopted.** Gate 2 fails for both quants; keep
`smallbook_x2` as the trial default (revert seam `ANSWER_MODEL=qwen2.5:7b`
unchanged). Next candidates in order: (1) x2d augmentation targeting the
deterministic failure classes above; (2) the q8-of-the-same-weights effect
suggests exporting and testing x2's own q8 before any 7B/business
conclusion — x2 q4 was never quant-tested either; (3) re-decide the
3B-vs-7B question only after x2d, with matched repeat runs to absorb the
measured seed variance.

**Decision (user, 2026-10-14): option 1 accepted** — keep `smallbook_x2`;
`x2d` is the next data build. The non-adopted models (`smallbook_x2c`,
`smallbook_x2c_q8`, `smallbook_x2_seed1234`) were deleted from ollama and
their local GGUF copies removed after this record; LoRA adapters kept
(`data/models/*_lora.zip`) so any quant can be re-made without retraining;
the captured Modelfile is in `evidence/x2c-session-2026-10-14/`.
