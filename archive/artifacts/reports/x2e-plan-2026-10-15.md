# x2e plan — pre-registered gate (2026-10-15)

Written **before training**, per the repo rule (the gate is pre-registered, the
run answers it). Build: `x2e-build-2026-10-15.md` (475 rows: 395 cited + 81
refusals, 27B-captured). Training: `finetune-colab-2026-10-13.ipynb` v8

## The pre-registered adoption gate

1. **Battery, both modes** (`step2-battery.py`, ask + answer): golden ≥ 8/10,
   typos / probes / coherence PASS, France an exact refusal; exactly one
   listener on the port.
2. **Sealed suite, 10 draws** (the standing bar): adopt only if **total ≥
   140/160** — the 7B bar x2d missed at 111/160. If below 140: adopt only by
   explicit user decision AND with **every class ≥ x2d's** (no regressions),
   recorded in the verdict doc.
   - Expected directions from the build: fragment ↑ (20 new fragment
     targets), order flips ↑ (17 new flip rows), bare ↑, column/row ↑ (x2d was
     0/10); `why does` stays a refusal (recorded ceiling, not a regression).
3. **Loops**: 0 cap-stops and 0 `repeat5 ≥ 3` draws on the suite.
4. **Reporting**: Turn-1 pass rate and retry-rescued pass rate reported
   separately (the retry stays; the external review's ask).
5. **Controls**: out-of-book refusals exact; the 7B's violin leak must not
   appear.
6. **Quant spot-check**: q4 (default) vs q8 only if a wart appears; not an
   adoption condition.
7. **Second book** (portability): optional, time-boxed; not an adoption
   condition.

## Decision rule

- **Adopt** (flip `ANSWER_MODEL`) iff items 1, 3, 5 pass and item 2's bar is
  met — or the explicit-decision exception applies (below 140 but no class
  regressed).
- **Otherwise**: record, keep x2d, and walk the fallback ladder — trim/repair
  targets → mix old + new targets (keep the 7B's quote-first targets for the
  regressed classes) → two-step assistant (27B → 7B → 3B).
- **Revert seam unchanged**: `ANSWER_MODEL=smallbook_x2d` (or `=qwen2.5:7b` /
  `=smallbook_x2`).
