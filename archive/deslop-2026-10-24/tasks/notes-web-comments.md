# Web comments with a real "why" (removed by F7)

For the docs task to fold in. File and symbol are the original location.

- `web/next.config.ts`: static export. `next build` writes `web/out/`, which the engine serves at `GET /`. Dev runs `next dev -p 3100` against the engine on :8000. The Turbopack root is pinned because Turbopack otherwise infers its workspace root from a stray `package-lock.json` in the home directory (warning in the dev log).
- `web/lib/engine.ts` (engine base URL): the Next dev server on :3100 targets the engine on :8000. When the engine serves the page (production static export on :8000, :8020, etc.) the page is same-origin, so relative URLs ("") are used.
- `web/lib/engine.ts` (stream reader): EOF with no final/error frame means an engine crash or dropped socket. Without handling it the pane stays blank and the store's controller is never cleared. A non-JSON error body is tolerated and the status line is kept.
- `web/lib/anchor.ts` (`offsetInChunk`): `Range.comparePoint(p, 0) === 0` means (p, 0) is inside the range, i.e. the selection started in the parent container right before paragraph p. This keeps a selection in paragraph 2+ from resetting `start = 0`. `comparePoint` errors across detached nodes are ignored.
- `web/lib/anchor.ts` (selection measuring): offsets are plain-text characters over the chunk's `<p>` elements joined by `\n`. Heading and caption selections return `start: -1, end: -1` (heading selections are re-encoded with negative sentinel offsets, `start <= -100`, see `decodeHeadingOffset`, so a heading highlight never marks matching words in body paragraphs).
- `web/lib/anchor.ts` (snapping): whitespace is trimmed before word-snap; partial words auto-snap to whole word boundaries; a short lead-in or heading ending in `:` (<= 32 chars) that spans into the next paragraph snaps the start to the second paragraph.
- `web/lib/anchor.ts` (`resolveSelection`): cross-chunk selections take start chunk (from start offset to end of its text), intermediate chunks whole, and end chunk (0 to end offset), snapping the start and end to word boundaries. Quote span per role: try the direct quote first; for "start" use the longest word prefix present in the chunk, for "end" the longest word suffix.
- `web/lib/anchor.ts` (`splitParagraphSegments`): cut points come from user highlights, gloss ranges, and the citation range; for each slice the latest matching highlight wins, then gloss, then citation.
- `web/lib/answer.ts` (`reorderAnswer`): the engine writes quote-first (`[Ch. N] "quote"`, a gloss line, then `Asked as:` / `Read as:` disclosures). Reader-first rendering shows the gloss, then the quote in italics with its chapter chip; words are the engine's own, only order and styling change (owner decision 2026-10-15). Each citation quote is found in the answer whitespace-insensitively, in order, each search starting after the previous match; the text between matches is the gloss. If recovery is impossible (refusal, missing quote, quote not in the answer), `ok` is false and the caller shows the verbatim answer plus the chips row, so a citation is never lost. The tag closing a quote-first line is removed so the chip is the only chapter mark.
- `web/lib/store.ts` (health polling): the poll has a hard cap, never blocking input longer than 60 s. Backoff runs 500 ms -> 1000 ms -> 2000 ms (cap). Only an explicit `ready: false` from a reachable engine disables input (missing fields mean ready); a failed `/health` fetch (network error, 500, timeout) must not disable input.
- `web/lib/store.ts` (books): the engine's catalog is the truth; only books indexed on this machine are shown.
- `web/components/reader/Reader.tsx` (citation jump): smooth cubic-bezier ease-out scroll, with a late-paint correction for `content-visibility: auto` chunks (their height estimate shifts after paint). Reading progress is restored on initial book load; `[` and `]` cycle glosses, Escape clears; paragraphs fall back to `markQuote` when no segments apply.
- `web/components/margin/Margin.tsx`: the active gloss sits exactly at its anchor; the rest stack away in both directions without overlapping, sorted by desired position, ties by creation time. Crowded cards, or minimized cards that are not active and not streaming, render as mini pills. Below 1080 px a sheet replaces the margin.
- `web/components/reader/Composer.tsx`: closing the suggestions is delayed so click handlers can register. Shortcuts: `/`, Ctrl+K, Cmd+K.
- `web/components/reader/TopBar.tsx`: auto-tuck on scroll down, reveal on scroll up; theme picker uses a circular View Transition.
- `web/app/globals.css`: layout is a 3-column `.reader-grid`: left `.rg-rail` (>= 1260 px), center `.rg-prose` (`--m: min(calc(var(--read-size, 19px) * 34), 46rem)`), right `.rg-margin` (>= 1080 px, 320 px wide, 28 px gutter). Topbar is a 60 px fixed header. Inputs use a font size that prevents mobile Safari zoom on focus. Reduced motion is handled case by case, not with a blanket `0.01ms !important`. Paper grain is an SVG fractalNoise overlay.
- `web/app/tokens.css`: 5 themes (night default, paper, sepia, snow, ink), 4 pens (vermilion default, cobalt, moss, graphite; each one light and one dark tone), 4 highlighters (yellow, green, blue, pink). Fonts are offline system fonts only (GOAL.md: no external requests).
