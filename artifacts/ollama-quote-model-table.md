No source in this table measures quote-or-refuse or "text after a short required answer" directly, so those are not measured for every model.

**Best candidate to try: `granite4.1:8b`. A pull costs 5,348 MB (about 5.3 GB). Use `olmo-3:7b-instruct` (4,472 MB) as the runner-up with the cleanest same-harness win over qwen2.5:7b.**

Caveats:
- Granite 4.1, Falcon3, EXAONE, Gemma 3 and Qwen3-2507 scores are vendor-reported. Only Ai2's Olmo card (and the Cohere and TII tables) score qwen2.5:7b side by side, and none tests quote-or-refuse or post-answer verbosity. Run your own 30-question eval (answerable plus unanswerable) at temperature 0 before switching.
- Ollama's default tags hide thinking models: `qwen3:4b` and `olmo-3:7b` both resolve to *thinking* variants. Pin `qwen3:4b-instruct` / `olmo-3:7b-instruct` explicitly. qwen3:8b and qwen3.5 need `think:false`, which a single leaked `<think>` can break.
- Several "small" tags are multimodal by default (gemma3 4b, gemma4, qwen3.5, ministral-3). Command R7B and EXAONE 3.5 are non-commercial.
