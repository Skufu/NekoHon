# smallbook_x2 live trial — fragment-pattern observations (2026-10-14)

The user tests with real-world sloppiness: fragments ("what is", "Location"),
greetings ("hey", "warrup"), bare topics ("DE Lifecycle"), comparisons with
the order flipped ("DDR5 vs ddr4" / "ddr4 vs ddr5"), trailing letters
("speed of ddr5s"). That surface is where the finetune is weakest. Raw
repro of all ten queries on both models through the app seam (answer mode):
`probe-trial-queries-2026-10-14.{json,log}`.

## Classification

- **Model warts** (x2 false-refuses where the 7B answers, all in-book):
  Location, DE Lifecycle, ddr4-vs-ddr5 — same disease as CRU/Codd: the
  decision margin sits a hair from refusal on any form not memorized
  exactly.
- **Engine items** (model-independent, backlog — fix after the session so
  trial attribution stays clean): "hey" -> `Read as: "they"` over-repair on
  greetings; "ddr5s" plural not repaired by either model; "what is"
  degenerate input answered with a passage.
- **Both-models-bad**: "what is", "speed of ddr5s". The 7B is not clean on
  this surface either (stray `Not in this book.` inside an answer).

## Effect on the next session design (proposed)

Slot A (x2c) widens to this pattern: ~30 of the 167 answer rows swapped in
place (counts and ratio held) to perturbed forms — lowercase fragments,
order flips, abbreviations/plurals. Slot B stays the seed control.
Acceptance probe for x2c = this probe's ten queries plus the batteries;
target: match the 7B on the three model warts, keep refusals 2/2 and loops
at zero.

## Pre-registered swap gate (written 2026-10-14, BEFORE x2c trains)

Committed before seeing any x2c / seed-control numbers so the pass/fail
rule cannot be negotiated after the fact. Temperature 0 throughout;
fragment/loop checks count draws (>= 10), not single runs; recordings
land in dated probe logs.

For a candidate to replace the trial default:

1. Refusals: France + iops exact (2/2); no in-book false refusal in the
   sealed fragment suite beyond the 7B's own misses on the same suite.
2. Fragment suite (new file, sealed, never trained): per-class pass rate
   >= the 7B's (classes: fragment, greeting, bare topic, order flip,
   trailing letter). The ten queries above are NOT the suite — they are
   visible targets.
3. No loops: 0 length-stops in the capped sweep (all 21 battery questions
   x 5 draws) and in the fragment suite (x 10 draws).
4. Battery: pin-pass rate not worse than x2's recorded 18-19/21, compared
   at equal draw counts, not single-run counts.
5. Quant check: the candidate's warts persist at high precision (q8_0
   export of the same run) — a wart that vanishes at q8_0 is a
   quantization verdict, not a training verdict.
6. Revert rehearsal: `ANSWER_MODEL=qwen2.5:7b` starts and passes the
   battery once during the trial. Done 2026-10-14: golden 10/10 (bar 8),
   typos PASS, probes PASS, France PASS; default engine restored after.
   Evidence: `evidence/step2-battery/step2-battery-revert-rehearsal-2026-10-14.{json,log}`
   plus the env-seam launcher copy `start-revert-rehearsal-2026-10-14.bat`.

Clean-bench note: the 4 assisted bench items (contamination audit
`probe-contamination-2026-10-14.log`) are reported separately; gate
claims about bench numbers use the clean subset.

## Amendments 2026-10-14 (written pre-run, before any x2c or seed-control numbers exist)

Sources: `finetune-expert-review-2026-10-14.md`, `eval-harness-audit-2026-10-14.md`,
`loop-mechanism-analysis-2026-10-14.md`. Recorded now so the pass/fail rule
still cannot be negotiated after the fact.

- Equal-draws baseline (items 2-3): the 7B fragment suite was re-run at
  `--draws 10` (completed 2026-10-14; rates in
  `evidence/probe-fragment/probe-fragment-2026-10-14.model-qwen2.5-7b.{json,log}`);
  the earlier 3-draw 7B recording is superseded (kept as `.draws3` history).
  Per-class comparisons use 10 draws per item for both models.
- Battery bar (item 4): read as a bar of max(7B, x2) at equal draws (7B:
  20/21 and 21/21 recorded; x2: 19/21, 18/21, 18/21 across three recorded
  passes — a fourth file is field-identical to the third).
- Seed-control read-out (new): if the seed-control run (x2 file, seed 1234)
  matches the recorded x2 (refusals 2/2 exact; battery within 18-19/21 at
  equal draws; fragment classes no worse; 0 length-stops), the x2 recipe is
  seed-stable and the x2->x2c delta is read as data-attributable. If it
  diverges (>1 battery pin at equal draws, or a class x2 was clean on), n=1
  comparisons anywhere in this history are unreliable and x2c is judged only
  against the absolute thresholds above — never against one recorded x2 run.
- Loop counting (item 3): a length-stop counts as a loop conservatively, but
  the write-up must say when it is a cap truncation rather than repetition
  ('File Formats' on x2: coherent prose, 10/10 at the 300 cap; one
  fresh-load run stopped naturally at 243 tokens). Loop counts are recorded
  per item and per quant (q4 and q8).
- q4-vs-q8 (item 5), pre-registered interpretation: a wart persists at q8 if
  its q4 failure appears within +/-1 draw at q8 (10/10 vs >=9/10); it
  vanishes only if q8 is clean across all draws and the battery pin flips.
  Same harnesses, same draw counts for both quants.
- Assisted items: the corrected x2c build adds the case-twin pair `what does
  crud stand for` -> the CRUD battery golden (1.00 similarity) and the CRU
  typo probe (0.96). CRUD and CRU join the assisted list (with ingestion,
  enterprise-architecture, pragmatic x2, codd); clean-subset claims exclude
  them. Exact asked-form overlap stays 0 (measured 2026-10-14).
- Seal note: the 'what does etls stand for' item shares the 'what does X
  stand for' interrogative template with the corrected crud/raid cards
  (r=0.833 / j=0.667, zero content overlap). Declared a template twin
  pre-run (`SEAL_TEMPLATE_TWINS` in the probe): logged as a seal note, not
  an abort; its per-item numbers are reported with that caveat and never
  counted as clean trailing-letter evidence.
- Engine: `answer.py` sends `num_predict: 512` (a loop becomes a truncated
  answer, not a 120 s client timeout). Applies to every model equally;
  probe-side draws keep their own caps.
